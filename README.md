🌱 Hasiru-Usiru Mapper

A community-driven environmental mapping application focused on building greener and climate-resilient cities.

📌 Overview

Hasiru-Usiru Mapper is an Android application designed to help citizens identify, map, and monitor urban green spaces. The app allows users to tag existing trees, mark empty planting spots, identify tree species, and contribute to a shared environmental database.

The project aims to reduce the impact of urban heat islands and encourage community participation in environmental conservation through technology.

❗ Problem Statement

Urban areas are rapidly losing green cover, leading to increasing temperatures and environmental imbalance. Citizens often want to contribute by planting trees, but there is no proper platform to:

Identify green gaps
Track existing trees
Know suitable native species
Monitor environmental impact
🎯 Objectives
Promote urban greenery and biodiversity
Enable citizen participation in environmental monitoring
Create a digital tree census system
Encourage planting of native tree species
Build awareness about climate resilience
✨ Features
🌳 Tree Tagging
Add tree location using GPS
Upload tree photos
Identify species (simulated)
📍 Empty Pit Marker
Mark areas where trees are missing
Help municipalities identify plantation zones
🌿 Oxygen Score
Dynamic environmental score based on:
Tree girth
Species factor
📖 Species Guide
Information about native trees such as:
Neem
Honge
Peepal
🗺 Community Green Map
Shared map showing tagged trees and green gaps
